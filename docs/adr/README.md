# Architecture decision records

Change semantics or the public API only with an ADR here, then update [DESIGN.md](../DESIGN.md), then code.

Name files `NNNN-short-title.md` (for example `0001-token-refund.md`).

An ADR should state the decision, why, and the cost. v0.1 decisions D1–D26 already live in the planning notes and are reflected in DESIGN.md; do not reopen them without a new ADR.
