# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `v0.x` (pre-1.0) | Yes — best effort until `v1.0.0` |
| unreleased `main` | Yes — development tip |

## Reporting a vulnerability

Please report security issues privately via [GitHub Security Advisories](https://github.com/harshwagh21/reliq/security/advisories/new) for this repository.

Do not open a public issue for vulnerabilities until a fix is available or we ask you to.

We will acknowledge reports as soon as practical and coordinate disclosure.
